# Architecture Decision Records

Create an ADR when a decision changes a durable contract, has meaningful alternatives, or will otherwise need to be rediscovered later. Do not create one for routine implementation detail.

Name files as `NNNN-short-title.md`, for example `0001-gym-catalog-two-copies.md`.

Use this concise template:

```md
# NNNN — Decision title

Date: YYYY-MM-DD
Status: accepted | superseded

## Context

What problem or constraint required a decision?

## Decision

What was chosen?

## Consequences

Benefits, trade-offs, migrations or follow-up work.

## References

Links to the relevant code, issue, PR or test.
```
